# 技术说明：光学编码与三维反演

[English](technical-notes.en.md) · [项目首页](../README.zh-CN.md)

## 1. 坐标与离散场景

横向坐标 `x,y` 在散射片平面定义，深度 `z` 是点源到散射片的正距离。演示将 `x∈[-55,55] mm`、`y∈[-45,45] mm` 离散为 `20×16` 点，并在 `z={0.75,0.95,1.10,1.55,1.85,2.20} m` 上建立体素。数组统一使用 `(z,y,x)` 轴序。

场景构造器按正视投影在每个 `(x,y)` 上选择最近的可见表面。它适合演示不透明场景的遮挡，不是通用网格光栅器，也不生成阴影或互反射。

## 2. 随机相位屏与传播

默认采样配置如下：

| 量 | 数值 |
| --- | ---: |
| 波长 `λ` | 532 nm |
| 采样网格 | 96×96 |
| 传感器像素间距 | 8 μm |
| 有效采样面宽度 | 0.768 mm |
| 相位屏到传感器距离 `L` | 3 mm |
| 相位相关长度 | 2 px |
| 相位标准差 | 2.5 rad |
| 角谱传播零填充倍数 | 2 |

相位由白噪声经过高斯频域滤波得到，并按目标标准差缩放。透射率写作 `T(x,y)=exp(iφ(x,y))`。每次标定和拍摄复用同一张相位屏；seed 改变后，相位纹理和 PSF 字典都会改变。

对位于 `(x_s,y_s,z)` 的点源，散射片上的球面波近似为：

```text
r(x,y) = sqrt((x-x_s)^2 + (y-y_s)^2 + z^2)
U_d(x,y) = A exp(i k r) / r,  k = 2π/λ
Σ_pixels |U_d|² = 1
```

场通过散射片后为 `U_d T`。传感器面使用角谱传递函数传播：

```text
H(f_x,f_y) = exp(i k L sqrt(1 - (λf_x)² - (λf_y)²))
U_s = F⁻¹{F{U_d T} H}
h_j = |U_s|²
```

只保留传播频率，倏逝频率置零。FFT 前对复场零填充，传播后裁回传感器的有限采样面。裁切后不再对 PSF 归一化，因此其能量和表示传感器捕获比例。seed 7 演示中，各 PSF 捕获比例范围为 `0.794–0.944`，中位数为 `0.879`。

## 3. 非相干测量与坏点掩膜

对 `N` 个候选体素，令 `x_j≥0` 为亮度系数、`h_j` 为第 `j` 个 PSF，则无噪声传感器图像为：

```text
y = Σ(j=1..N) x_j h_j
```

这是非相干强度叠加，不是复振幅相干叠加。模拟先形成期望强度图，再可选地采样泊松光子计数，并叠加高斯读出噪声：

```text
y_photon = Poisson(photon_count × y) / photon_count
y_noisy = y_photon + Normal(0, noise_std²)
```

演示使用 `photon_count=500000`。`noise_std=0` 表示没有额外高斯项，不表示没有泊松噪声。

若像素在测量或相关标定 PSF 中任一处无效，该像素不进入目标向量。演示将无效值保存为 NaN，并使用共同有效掩膜；96×96 网格中有 8,136 个有效采样点。缺失像素不是零强度观测。

## 4. 非负 L1 与空间平滑

把每张有效 PSF 展平为字典矩阵 `D` 的一列，内部按 L2 范数归一化。基础目标为：

```text
minimize_x  0.5 ||D x - y||²₂ + λ ||x||₁
subject to  x ≥ 0
```

`λ = relative_l1 × max(Dᵀy)`，因此参数 `relative_l1` 相对于当前测量的最大字典相关值缩放。默认值为 `0.003`。FISTA 通过幂迭代估计步长界，迭代至最大步数或相对系数变化低于容差。输出前撤销 PSF 列归一化，恢复亮度系数尺度。

可选平滑项按每个深度层分别惩罚横向相邻差分：

```text
objective += (μ/2) Σ_z Σ_(neighbor pairs in x,y) (x_a - x_b)²
```

默认 `μ=0.03`。它不会跨深度平滑，也不是物体几何或表面法线先验。单表面模式先在完整体积上求解，再保留每条射线最强的深度，只对这些选中 PSF 重新拟合亮度。

## 5. 残差门控的深度坐标更新

深度精修仅在单表面支持上执行。先计算有效像素上的相对残差：

```text
ρ = ||y_fit - y||₂ / max(||y||₂, ε)
```

若 `ρ > depth_refinement_residual_threshold`，算法原样返回单表面重拟合结果，不做深度交换。默认门限为 `0.05`。该门限用于避免模型拟合很差时继续把随机噪声解释为深度信息。

若 `ρ` 不超过门限，则对当前活动的每条 `(x,y)` 射线：

1. 从测量残差中移除该射线当前 PSF 的贡献。
2. 对该横向位置所有标定深度计算非负 L1 更新分数。
3. 选择分数最高的深度，并解析更新强度；分数并列时保留当前深度。
4. 以固定 seed `42` 的伪随机顺序扫描，最多重复 `depth_refinement_steps` 轮，无系数或深度变化时提前停止。

这是贪心坐标优化，受初始深度支持影响，不能保证全局最优。它不会从初始活动射线以外创建新的空间位置，也不适用于透明物体或同一视线上的多个真实表面。API 默认不启用该步骤；若开启，必须同时设 `single_surface=True`。

## 6. 公开 NPZ 数据字典

[`meeting_scene_results.npz`](../data/meeting_scene_results.npz) 使用 NumPy 压缩 NPZ 格式。主要数组如下：

| 键 | 形状 | 含义 |
| --- | --- | --- |
| `phase_screen_rad` | `(96,96)` | 固定相位屏，单位 rad |
| `calibration_psfs_partial` | `(1920,96,96)` | 部分有效的逐体素标定 PSF，缺失像素为 NaN |
| `sensor_mask` | `(96,96)` | 有效像素布尔掩膜 |
| `measurement` | `(96,96)` | 传感器测量，缺失位置为 NaN |
| `true_volume` | `(6,16,20)` | 合成真值亮度体 |
| `reconstructed_volume` | `(6,16,20)` | 重建亮度体 |
| `source_positions_xyz_m` | `(1920,3)` | 每个 PSF 对应的 `(x,y,z)`，单位 m |
| `depths_m`, `x_positions_m`, `y_positions_m` | `(6)`, `(20)`, `(16)` | 三轴网格坐标 |

NPZ 还保存 `spatial_smoothness`、`relative_l1`、`single_surface`、`sensor_size`、`depth_refinement_steps` 和残差门限。亮度是仿真系数，不等同于真实反射率或绝对光通量。
